# 🎓 Student Management System

A full-stack CRUD application built with **Node.js**, **Express.js**, **MongoDB**, **Mongoose**, and **EJS**. This project allows users to manage student records with profile image uploads through a clean and responsive interface.

## ✨ Features

- ➕ Add new students
- 📋 View all students
- ✏️ Update student information
- 🗑️ Delete students
- 🖼️ Upload profile images
- 💾 MongoDB database integration
- 📱 Responsive user interface

## 🛠️ Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- EJS
- HTML5
- CSS3
- JavaScript

## 🚀 Installation

```bash
git clone https://github.com/your-username/express-mongodb.git

cd express-mongodb

npm install

npm start
```

Open your browser:

```
http://localhost:3000
```
